================================================================
ROCCO — HELPER EXPERIENCE
================================================================

Goal:
  A helper can sign up, browse open tasks, accept one,
  and mark it complete.

Step 1 — Create these two tables in Supabase SQL Editor:

  -- helper_profiles
  create table helper_profiles (
    id uuid primary key default gen_random_uuid(),
    user_id uuid not null references users(id) on delete cascade unique,
    bio text,
    skills text[],
    verification_status text not null default 'pending'
      check (verification_status in ('pending', 'verified', 'rejected')),
    background_check_date date,
    years_experience int,
    created_at timestamptz not null default now()
  );

  -- bookings
  create table bookings (
    id bigint generated by default as identity primary key,
    task_id bigint not null references tasks(id) on delete cascade,
    helper_id uuid not null references users(id) on delete cascade,
    status text not null default 'accepted'
      check (status in ('accepted', 'in_progress', 'completed', 'cancelled')),
    accepted_at timestamptz not null default now(),
    completed_at timestamptz,
    unique (task_id)  -- one helper per task
  );

  -- Enable RLS + basic policies for development
  alter table helper_profiles enable row level security;
  alter table bookings enable row level security;

  create policy "Public all helper_profiles"
    on helper_profiles for all to anon using (true) with check (true);

  create policy "Public all bookings"
    on bookings for all to anon using (true) with check (true);

Step 2 — Build the pages:

  1. Helper Signup form
     File: src/pages/HelperSignup.tsx
     Fields: bio, skills (multi-select or checkboxes),
     years of experience
     - Insert into helper_profiles with the logged-in
       user's id as user_id
     - Default verification_status to 'pending'
     - On success: redirect to /browse-tasks

  2. Browse Open Tasks
     File: src/pages/BrowseTasks.tsx
     - Fetch all tasks where status = 'open'
     - Show category, title, suburb, offered amount, date
     - Each card has an "Accept" button (only for logged-in
       helpers)

  3. Accept Task action
     File: src/components/AcceptTaskButton.tsx
     - On click:
       a. Insert a row into bookings
          (task_id, helper_id = current user id,
           status = 'accepted')
       b. Update the task: status = 'assigned',
          assigned_helper_id = current user id
     - On success: navigate to /helper/bookings

  4. My Bookings
     File: src/pages/MyBookings.tsx
     - Fetch bookings where helper_id = current user
     - Join to tasks to show task title, suburb, amount
     - "Mark Complete" button on each accepted booking:
       a. Update booking status = 'completed',
          completed_at = now()
       b. Update task status = 'completed'
     - Move completed bookings into a "Past" section

Deliverable this week:
  A helper can sign up, browse open tasks, click Accept, and
  see the accepted task in My Bookings. Tasks move from
  "open" to "assigned" in the database.
